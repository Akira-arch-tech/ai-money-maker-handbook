# 千问镜界对战 · Sync Arena Demo

模拟 **两位千问 AI 眼镜用户** 进入同一 3D 空间，实时互动：

- 看见对方位置与朝向（WebSocket 同步）
- 用「眼镜语音指令」生成 Tripo 风格 3D 物体
- 抢能量球计分（轻量竞技）

> 这是产品验证 demo，不是真机固件。眼镜输入用按钮模拟；3D 物体用本地几何体代替 Tripo API 结果。

## 谁负责什么

| 角色 | 负责 |
| --- | --- |
| 浏览器窗口 A / B | 模拟一位眼镜佩戴者的画面与操作 |
| `client.js`（Three.js） | 3D 场景、移动、拾取 |
| `server.mjs`（WebSocket） | 房间、位置广播、语音生成物体、计分 |
| Tripo（未来真接） | 把拍照/指令换成真实 mesh；本 demo 用占位几何体 |

## 数据怎么流

```
用户语音按钮 → 本机发出 voice 消息
    → 房间服务器生成物体 / 更新分数
    → 广播给房间内另一位
    → 对方 Three.js 场景出现同一物体
```

移动同理：`move` 消息约每 50ms 同步一次。

## 本地运行

```bash
cd demos/qwen-sync-arena
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`，再开一个窗口，**房间号填一样**（默认 `DEMO`）。

## 操作

- **WASD / 方向键**：移动
- **鼠标拖动**：转视角
- **底部按钮**：模拟眼镜语音（生成方块 / 球体 / 路锥 / Tripo 数字样）
- **走近绿色发光球**：自动拾取计分

## 和真千问眼镜的对应关系

| Demo | 真机路径（未来） |
| --- | --- |
| 语音按钮 | 千问开放平台 Skill + 语音意图 |
| 本地几何体 | Tripo API 图生 3D / 文生 3D |
| WebSocket 房间 | 业务侧实时房间（或 RTC） |
| 浏览器画面 | N1 侧以 App 预览为主；S1 可叠简易 HUD |

## 最小商业化验证（主业向）

把「抢球」换成「两人同时看同一货样 3D、点头确认选款」——付费方是跨境买手/供应商，价值是减少寄样往返。本 demo 先验证 **双人实时同空间** 是否成立。
